# Cocktail Feed 🍸

A mini project developed as part of the App Brewery London Fullstack Course to practise working with APIs using Express and Axios.

Cocktail Feed is a cocktail discovery website that displays a selection of random cocktails on the homepage. Users can browse the available cocktails, select one they like, and view its full recipe, including ingredients and preparation instructions.

## Technologies Used

- Node.js
- Express.js
- Axios
- HTML
- CSS
- JavaScript

## API

This project uses [TheCocktailDB API](https://www.thecocktaildb.com/) to retrieve random cocktail recipes and ingredient information.

## How to Run

1. Clone the repository.
2. Navigate to the project folder.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   node index.js
   ```

5. Open your browser and visit:

   ```
   http://localhost:3000
   ```

## Purpose

This project was built to practise API integration, making HTTP requests using Axios, and serving dynamic content using Express.
